The Big Number
58%
of Claude use inside companies
goes through personal accounts, not the company license

Cyberhaven tracks how data moves in and out of AI tools on work laptops at the firms that use its software. In its 2026 report, 58.2% of Claude use happened through personal accounts. For ChatGPT it was 32.3%, for Gemini 24.9%. The reason is not hard to guess. Claude Code is a very good tool, and at most organizations there was no institutional way to get it. People used what they had.

At the Bank, that gap is now closed. Claude Enterprise is approved for Strictly Confidential data, and it is the only coding agent with that level of approval. GitHub Copilot is approved up to Official Use Only. mAI and Microsoft 365 Copilot are approved for Strictly Confidential too, but they are not coding agents. So there is a growing set of approved tools that keep data secure and private, and it now includes Claude Code. The interface is the same whichever license you sign in with. What differs is configuration you cannot see. This issue is about telling the two apart.

Source: Cyberhaven 2026 AI Adoption & Risk Report (February 2026); the per-tool figures are in the accompanying post. Data from firms that bought monitoring software, not from the Bank.

In Case You Missed It

Understand Claude Enterprise and Other WB AI Tools

A quick recap of Impact Analytics’ October 22 training on Claude Enterprise and the other AI tools at the Bank (slides here). The Bank has approved Claude Enterprise, GitHub Copilot Enterprise and mAI for non-public data, and provides licenses for Claude and GitHub Copilot on request. Claude Cowork is open to all staff with manager approval, since the business unit pays for usage. Claude Code is not yet available Bank-wide, but that is coming. Many of us also have paid Claude or ChatGPT accounts for personal use, and keeping the two apart is not always straightforward.

1.  An interface is not a model. Claude Code, GitHub Copilot and mAI are interfaces: software that packages your request. Claude Opus or GPT-5.5 is the model that answers it. Several interfaces use the same models. Neither the interface nor the model determines whether your data stays private. That depends on where the model runs and who has access to that server, and genuinely private places to run a model typically require an enterprise license.
2.  Same interface, different license, different rules. Claude Enterprise runs on servers Anthropic cannot look into and is approved for Strictly Confidential files. A personal license runs the same models on servers where your conversations can be kept and used. If you are using Claude with a personal license, you can only give it access to files classified as Public, even with model training switched off.
3.  Why Enterprise feels expensive. Enterprise is billed per use, and running AI models is expensive. Consumer plans are flat-rate, with usage caps and different data terms, so the same $20 goes much further there. Part of what the Enterprise price buys is the data protection.
4.  Pick the tool by the data. Identified or confidential data (PII scans, cleaning raw survey data, matching on names): Claude Enterprise. Writing or fixing code, with a codebook and made-up data in place of the real thing: GitHub Copilot, the default for coding. Public data, generic code, learning a package: a personal license is fine, with the safety settings from the training slides. When in doubt, Claude Enterprise.
5.  Know which account you are in. In Claude Code, type /status. In Claude Web or Desktop, look for the WB logo and your email at the bottom of the sidebar. The VS Code extension follows whichever account Claude Web is signed into at the start of that conversation. After switching profiles, start a new session. Never continue a conversation that began under the other account.

Try This Today  ·  10 minutes

Find out which account you are actually using, and make the personal one safer. No project files needed.

1. Check Claude in VS Code. Open the Claude panel and type /status. If it shows your WB email, you are on Claude Enterprise. If it shows a personal address, that is the account every Claude task in VS Code has been going to.

2. Check Claude Web and Desktop. Open the sidebar and look at the bottom. WB logo and WB email means Claude Enterprise. Anything else is personal. If you have both, note which browser or app is signed into which.

3. Switch Claude Code from Auto to Manual. Auto approves costly actions on its own and can read files outside your workspace. Manual asks first. The training recommends Manual on every account, and insists on it for personal ones.

4. Sort one task from this week. Take something you are about to hand to an AI tool and ask: what will the tool see? Real data, or a codebook? Unpublished numbers, or public text? Then match it to point 4 above. If the honest answer is “the real data”, it goes to Claude Enterprise, whatever it costs.

Have more than 10 minutes? Set up two Claude Code profiles, one for Claude Enterprise and one for your personal account, each with its own login and settings. Then you pick the account by opening the profile and never log out again. Steps are in Appendix B2–B3 of the training slides. Or try Workflow B on one dataset: ask Claude Enterprise for a codebook and fifty made-up rows, strip anything that names a place or a person, and do the coding in GitHub Copilot. Field Notes  ·  beyond the trainings

Ask again before you switch tools

The Claude Enterprise training’s ladder says: start in GitHub Copilot, move to Claude when GitHub Copilot struggles. But how many tries counts as struggling?

A study asked a model to write code for 1,088 published economics and finance papers. Simply asking again improved the code, with shrinking returns each time. A person pointing out what was wrong improved it more. Field Notes takes the result apart, including what the paper cannot tell you, and turns it into a rule for when to climb a rung.

The Big Number
100×
price gap per token between the largest
and smallest Claude model this week

On Anthropic’s price list this week, the largest model (Fable 5.1) costs $10 per million tokens you send it and $50 per million it writes back. The smallest (Haiku 5.5) costs $0.10 and $0.50. A hundredfold gap, in both directions. Opus and Sonnet sit in between at $4 and $2. Enterprise usage is billed at these rates, so the model you pick in the dropdown is the biggest single lever on what your unit pays.

A hundredfold price gap does not mean the small model is a hundred times worse. For proofreading a paragraph or explaining a Stata option, it is usually not worse at all. Impact Analytics’ November 5 training was about matching the model to the job, and two other habits that cut the bill without touching the quality of the work.

In Case You Missed It

Using AI Agents Cost Effectively

A quick recap of Impact Analytics’ November 5 training on using AI agents cost effectively. Token limits are already a real constraint at the Bank, and Enterprise credits come out of a budget. The training was about three habits that cut the bill, and why the habits matter more than the current prices do.

1.  Cheap tokens won’t last. Today’s personal-plan prices are subsidised by companies that want us to get used to big models for everything. Setups with real privacy guarantees are not subsidised at all. Those of us on Copilot licences for six months have already had a small taste of running out. The training’s image: we can afford the V8 today, so now is the time to learn to drive the hybrid.
2.  Use the smallest model that does the job. If the semi-truck is your most capable vehicle, you still don’t take it to buy milk. A small model proofreads a paragraph as well as a large one. There is no fixed cutoff, and small models keep getting better, so try the smaller one first and move up when it falls short.
3.  A memory file is a shopping list. Without one, the agent buys the whole store on every request: it re-reads your project to learn what language you use and where the code lives. Write that down once, in AGENTS.md or CLAUDE.md, and it is loaded every time. A good memory file also makes a smaller model good enough, because the agent is not wasting its attention on discovery.
4.  Start a new session for each task. Models don’t remember. On every request the whole conversation so far is sent again and processed again, for every word of the answer. Ten tasks in one chat means the tenth task pays for the previous nine, and the agent’s attention is split across all of them. Use the plus button. If you want to reuse a good prompt, copy it into a fresh session.
5.  Read the meter. Copilot’s chat panel shows how full the context window is. At the end of a task, under 5% suggests you used a bigger model than you needed; over 95% suggests a model too small for the job, and details were probably lost. In Claude Code, /cost shows what the session has spent and /context shows what is filling the window.

Try This Today  ·  10 minutes

Make one routine task cheaper, and find out whether it got worse.

1. Write down your numbers. Claude: Settings, then Usage. Copilot: the premium requests left this month. Put them in a text file with today’s date. One line. You will want the trend later.

2. Look at what you are carrying. In the chat session you have open right now, check Copilot’s context meter, or type /context in Claude Code. If most of it is tool output from tasks you finished an hour ago, that is what you have been paying to resend on every request since.

3. Start a fresh session and pick a small model. Choose a routine task: proofread a paragraph, rename variables to match a convention, explain an error message. Switch the model picker to the smallest model on offer before you send it.

4. Judge the answer as strictly as you would the big model’s. Did it get anything wrong that the larger model would have got right? If not, that task has a new default. Add that to the text file too.

Have more than 10 minutes? Open the memory file of the project you spent most on this month. Add the three things the agent had to ask you, or got wrong, this week. Then read the Deep Dive: a half-hour routine for doing this once a month, with the numbers your tools already give you.

Field Notes  ·  beyond the trainings

Same model name, different answer

Switching to a smaller or newer model is the fastest way to cut the bill. If the model produced a variable in your analysis, it is also a change to your instrument.

Three political scientists re-ran the same text-coding tasks on the same models every month for most of 2024. The AI beat crowdworkers on accuracy and lost on stability. Fixing the temperature did not help, one model stopped existing mid-project, and the re-estimated coefficients came out a third the size.

## Which Day 0 sessions do I need?

You can skip anything you already have set up. Answer these questions:

| Question | If **no**, attend |
|---|---|
| Have you used GitHub before? | Set up GitHub, and Intuitive Introduction to Git/GitHub |
| Is your project already using GitHub for version control? | Migrating an existing project to GitHub |
| Have you used an IDE such as VS Code (as opposed to only Stata's do-file editor or RStudio)? | Intro to IDEs (VS Code), and Set up VS Code |
| Do you have Python or R installed? | Set up command line software |
| Do you have GitHub Copilot set up in VS Code? | Set up a coding agent |

During the main week there is limited time to help with accounts and software, which is why Day 0 exists.

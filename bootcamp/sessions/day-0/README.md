# Day 0 (October 1): Prerequisite: Setup for AI-enabled Research

> **Note:** Prerequisite for Days 1-3, optional for staff who are already using these tools.

## Description

### Objective
Participants gain the foundational skills for reproducible workflows. They understand and set up the accounts and software required to use coding agents on WBG laptops. The main course (Oct 5-8) has these foundations as pre-requisites. If staff already have these skills, they do not need to attend the foundations day.

### Expected Outcomes
- All participants have a GitHub repository for a current project and make at least one commit to the repository
- All participants set up VS Code and use it for at least one interaction with GitHub CoPilot/Claude Code

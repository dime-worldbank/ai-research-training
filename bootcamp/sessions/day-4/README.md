# Day 4 (October 8): AI-enabled Workflows for Advanced Users

> **Note:** A deeper dive for staff with experience using AI workflows.

## Description

### Objective
Participants gain hands-on experience with the full spectrum of advanced AI-enabled research workflows available at the WBG. By the end of the day, staff will be able to access and use the WBG's AI API for custom applications, apply AI to geospatial analysis, use Git-based workflows to verify and validate AI outputs, harness multi-agentic systems for complex research tasks, and build AI-assisted dashboards and web applications — equipping them to go beyond individual productivity gains and design scalable, reproducible, and shareable AI workflows for their teams.

### Expected Outcomes
- Participants set up a MEGA workspace and successfully query the World Bank AI API
- Participants use their own GitHub repos to review and verify AI outputs for their projects
- Participants set up one multi-agentic workflow for their project

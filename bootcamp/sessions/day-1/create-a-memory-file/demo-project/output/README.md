# Output

Everything in this folder is created by code. Do not edit these files by hand,
re-run `python run_all.py` instead.

## Tables (`tables/`)

| File | What it shows | Created by |
|---|---|---|
| `summary_by_district.csv` | Number of households, average household size, average income and share with electricity, per district | `code/analysis/summary_tables.py` |
| `electricity_by_area_type.csv` | Share of households with electricity in urban vs rural districts | `code/analysis/summary_tables.py` |
| `income_groups.csv` | Number of households in each income group | `code/analysis/summary_tables.py` |

## Figures (`figures/`)

| File | What it shows | Created by |
|---|---|---|
| `income_by_district.png` | Bar chart of average monthly income per district | `code/analysis/figures.py` |
| `electricity_by_area_type.png` | Bar chart of electricity access, urban vs rural | `code/analysis/figures.py` |

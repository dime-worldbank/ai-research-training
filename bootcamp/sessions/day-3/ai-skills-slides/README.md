# AI skills for presentations

Day 3 hands-on session. Participants use an AI skill to create a new slide deck
from a reproducibility package, and to improve and rebrand an existing deck
using the supplied paper and supporting outputs.

## What's in this folder

| Path | Contents |
|---|---|
| [`ai-skills-slides.qmd`](ai-skills-slides.qmd) | Slide source |
| `index.html` | Rendered slides (open in a browser) |
| [`skills/`](skills/) | The `prepare-slides` skill |
| [`materials/`](materials/) | Demo project with two exercises (create a deck, improve a deck) |

## Try it

1. Download the [skill](https://github.com/dime-worldbank/ai-research-training/releases/download/prepare-slides-latest/prepare-slides.zip) and unzip it.
2. Choose a project:
   - **Your own project:** follow the steps in
     [skills/README.md](skills/README.md).
   - **The demo project:** download the
     [demo project](https://github.com/dime-worldbank/ai-research-training/raw/refs/heads/main/bootcamp/sessions/day-3/ai-skills-slides/materials/demo-projects.zip)
     and see [materials/README.md](materials/README.md) for the two exercises.

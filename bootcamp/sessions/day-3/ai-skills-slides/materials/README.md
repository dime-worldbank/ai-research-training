# Demo Project



The demo project is supplied in place of your own research project. It contains materials for two exercises.



## Exercise 1: Prepare a new deck



A reproducibility package for [Factor Market Failures and the Adoption of Irrigation in Rwanda](https://www.aeaweb.org/articles?id=10.1257/aer.20210059).



Use these materials to prepare a slide deck from research files.



## Exercise 2: Improve an existing deck



A synthetic research paper, supporting results and figures, and a 14-slide PowerPoint deck that needs improvement.



Use the paper and outputs to review and improve the deck’s content, structure, visuals, and branding.

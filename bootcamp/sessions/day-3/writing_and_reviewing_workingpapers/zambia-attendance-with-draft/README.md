# Zambia School Meals — WITH draft (review-flow demo)

Fictional project for the bootcamp. A full draft exists
(`paper/draft.qmd`) and it contains **seeded defects** — the exercise is to
find them with `wb-paper-review`. Instructor answer key:
`INSTRUCTOR-seeded-defects.md` (don't peek first).

The `wb-paper/` folder is **pre-baked** (profile, three personalized critics,
ledger), so you can go straight to reviewing without the setup interview.
Note how the profile's fear ("reviewers will doubt parallel trends") and the
past referee report (`wb-paper/references/feedback/`) shaped the critics'
priorities — that's the personalization the setup skill produces.

## Suggested test script

```
1. git init && git add -A && git commit -m "baseline"   # enable commit conventions
2. Invoke wb-paper-review.
3. Scope: Methodologist · accuracy · Results section.   # fast, unambiguous hits
4. Triage: accept one, reject one, CHALLENGE one.        # exercise the protocol
5. Scope: Methodologist · design · full draft.           # the parallel-trends story
6. Hand off accepted comments → wb-paper-write revise mode.
7. Check wb-paper/log.md and git log after each step.
```

Everything here is fictional training material; several bibliography entries
are simplified or deliberately fabricated (see the answer key).

# AI skills for automating tables and charts

Day 2 hands-on session. Participants use an AI skill to turn a table or figure
that was made by hand (in Excel or Word) into one that Stata, R, or Python code
produces from the source data.

## What's in this folder

| Path | Contents |
|---|---|
| [`reproduce-manual-exhibit.qmd`](reproduce-manual-exhibit.qmd) | Slide source |
| `index.html` | Rendered slides (open in a browser) |
| [`skills/`](skills/) | The `reproduce-manual-exhibit` skill |
| [`materials/`](materials/) | Three demo projects (R, Excel, Stata) with set-up steps and prompts |

## Try it

1. Download the [skill](skills/reproduce-manual-exhibit.zip) and unzip it.
2. Choose a project:
   - **Your own project:** follow the steps in
     [skills/README.md](skills/README.md).
   - **A demo project:** download one from [materials/](materials/) and follow
     the set-up steps in [materials/README.md](materials/README.md).

# Day 2 (October 6): AI Tools For Data Acquisition and Analysis

## Description

### Objective
Participants learn how AI can transform every stage of the data pipeline — from survey design and data collection through to cleaning, analysis, and the production of publication-ready outputs. By the end of the day, staff will have hands-on experience using AI agents within Survey Solutions and SurveyCTO, applying AI to data quality checks and code improvement, and generating reproducible tables and charts with reusable AI skills. The day equips researchers with practical, time-saving workflows that integrate seamlessly into existing data processes — reducing the burden of routine tasks and freeing up more time for the analytical work that drives impact.

### Expected Outcomes
- Participants use AI tools to program a survey instrument (their own questionnaire, or a demo questionnaire)
- Participants apply reusable, AI-enabled workflows for data quality checks on their own data (or a demo dataset)
- Participants use AI skills to review and improve one existing code file
- Participants use AI skills to create at least one table or chart using their own data

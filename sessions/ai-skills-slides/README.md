# Using AI to Automate Research Outputs

Materials for the hands-on session on using an AI skill to create, improve, and
rebrand research presentations.

This session introduces the `prepare-slides` skill and uses it in two
exercises. In the first exercise, participants create a new deck from a
reproducibility package. In the second, they improve an existing slide deck
using the supplied paper and supporting outputs.

**Objective:** produce a well-structured, presentation-ready slide deck while
keeping the author in control of the narrative, evidence, visual choices, and
final format.

> **Short on time or unable to complete the setup?** You can watch the live
> demonstration and repeat the exercises later using the materials provided
> here.

## Before the session

Please complete the following setup if you want to follow along on your own
computer.

### 1. Visual Studio Code

Install **Visual Studio Code** from the Software Center.

### 2. Access to an AI assistant in VS Code

You need one of the following, signed in inside VS Code:

- **GitHub Copilot:** use the Copilot Chat extension with access to a Claude
  model
- **Claude Code:** use the Claude Code extension linked to a personal or team
  account

Either option works. Open the chat panel in VS Code and confirm that it
responds.

### 3. The prepare-slides skill

Download the skill ZIP:

**[Download the prepare-slides skill](https://github.com/dime-worldbank/ai-research-training/releases/latest/download/prepare-slides.zip)**

Unzip it and keep the complete `prepare-slides/` folder. During the session,
you will copy this folder into the project used for the exercise.

### 4. The demo project

The demo project is supplied in place of your own research project. It contains
two exercise folders:

- `exercise-1/` contains a reproducibility package for creating a new deck
- `exercise-2/` contains a synthetic paper, supporting outputs, and a
  PowerPoint deck that needs improvement

Download the demo project:

**[Download the demo project](https://github.com/dime-worldbank/ai-research-training/raw/refs/heads/main/sessions/ai-skills-slides/materials/demo-projects.zip)**

Unzip it somewhere easy to find and leave the folder structure unchanged.

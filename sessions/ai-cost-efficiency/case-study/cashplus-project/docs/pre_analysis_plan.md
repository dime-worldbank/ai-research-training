# Cash Plus: Pre-Analysis Plan
Registered with the AEA RCT Registry. Version 3.

## 1. Outcome family: household consumption per capita
Hypothesis H1.1: Households assigned to the cash plus arm will show a change in household consumption per capita relative to the control arm at endline. We measure household consumption per capita using the household survey module 1A, administered to the primary respondent. The primary specification regresses the endline outcome on treatment assignment, the baseline value of the outcome, and strata fixed effects, with standard errors clustered at the village level, the unit of randomization. We will adjust for multiple hypothesis testing within the household consumption per capita family using sharpened q-values. Heterogeneity will be examined by female headship, baseline poverty, and distance to the nearest market. Attrition will be tested by regressing an indicator of non-response on treatment, and Lee bounds will be reported if differential.
